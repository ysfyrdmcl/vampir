# Rol Kartı Görselleri

Bu klasördeki dosya adlarını değiştirme. Uygulama bu dosyaları sabit adlarla okur.

## Dosyalar

- `villager.png`
- `vampire.png`
- `detective.png`
- `doctor.png`
- `hunter.png`
- `mayor.png`
- `guard.png`
- `lover.png`

## Önerilen teknik ölçü

- Kart oranı: `4:3`
- Önerilen çıktı: `1200x900 px`
- Minimum: `800x600 px`
- Format: `PNG` (sRGB)
- Dosya boyutu hedefi: `300 KB - 1.5 MB`

## Güvenli içerik alanı

- Üstten %10 ve alttan %15 alanı kritik yüz/ikon için boş bırak.
- Kart başlığı ve takım etiketleri görselin üstünde bind edildiği için orta alanı ana odak olarak kullan.

## Stil notu

- Koyu gotik arka plan + tek güçlü odak karakter.
- Rol renk dili:
  - Vampir: kırmızı/bordo
  - Köy tarafı (Köylü, Dedektif, Doktor, Avcı, Gardiyan): altın/amber vurgular
  - Aşık: sıcak amber + hafif kırmızı geçiş
  - Belediye Başkanı: altın + koyu taş dokusu
